连接你的 GitHub

使用仅允许更新主页仓库的访问令牌。连接只在当前页面有效。

  1. 在 GitHub 创建访问令牌 ↗
  2. 在 Repository access 选择 Only select repositories，仅选 Mowans.github.io。
  3. 确认 Contents → Read and write，然后生成令牌，粘贴到下面。无需其他写入权限。

令牌仅直接发送给 GitHub，不会保存到草稿、仓库或浏览器长期存储。不要将令牌发送到聊天中。
